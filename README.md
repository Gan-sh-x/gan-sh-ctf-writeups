## 🎨 Style guide

Colorful headings, badges, emoji, and compact tables make pages easy to scan. Technical notes remain accurate and written in my own words. Screenshots are optional; sanitized text and commands are enough when sharing is allowed.

## 🔐 Sharing rules

- For TryHackMe, do not publish flags, answers, exploit code written for a specific room, or step-by-step solutions while content is active. Treat a room as active unless TryHackMe marks it retired.
- For CTFs, check the event rules and disclosure policy before publishing.
- Do not include passwords, session cookies, API tokens, personal data, or copied challenge text.

See the [TryHackMe Acceptable Use Policy](https://tryhackme.com/legal/acceptable-use-policy) before posting room-specific material.
