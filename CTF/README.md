## 🎨 Write-up style

Use the [CTF template](Templates/ctf-writeup-template.md) for an emoji-led, readable layout. Use headings, tables, and small sanitized code blocks to make the method clear; omit flags and hidden answers.

## 🛡️ Publishing checklist

- Review the event's rules and disclosure policy before sharing.
- Omit flags, hidden answers, credentials, tokens, and private challenge data.
- Do not reproduce challenge statements, protected files, or another author's solution.
- Use your own words and sanitized evidence; redact real infrastructure details when required.
- Keep drafts private and recheck the rules before making the repository public.
