# TryHackMe Rooms

Add a folder for each room you have completed, using a short lowercase slug (for example, `recruit/`). Put the write-up in that folder as `README.md` and use the [room write-up template](../Templates/room-writeup-template.md).

Only add completion status after you have completed the room. Do not add flags or hidden answers. Check the room's rules before sharing any walkthrough details.
