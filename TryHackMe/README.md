## 🎨 Write-up style

Use the [room template](Templates/room-writeup-template.md) for a consistent layout with a room summary, scope, methodology, observations, and lessons learned. Color comes from the custom banner, badges, emoji headings, and tables; keep the technical steps readable and accurate.

## 🛡️ Publishing checklist

- Check the room's current sharing and disclosure rules before publishing. Under TryHackMe's current policy, treat content as active unless the platform marks it retired; do not publish step-by-step solutions for active rooms.
- Do not include flags, hidden answers, credentials, tokens, VPN details, or personal data.
- Avoid copying room task text, screenshots, or complete official solutions. Explain your own method in your own words.
- Redact target details that the room rules say must remain private.
- Keep this repository private while notes are drafts; review the rules again before changing repository visibility or sharing a link.

This GitHub folder provides a browsable list of Markdown notes. It does not create or submit a write-up on TryHackMe's own room page. See the [TryHackMe Acceptable Use Policy](https://tryhackme.com/legal/acceptable-use-policy) before publishing a room-specific walkthrough.
